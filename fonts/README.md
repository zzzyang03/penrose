# Fonts

v1 ships a CJK fallback (Source Han Sans / Noto Sans CJK, OFL) so ASS/SRT
glyphs do not silently tofu when the system font is Latin-only.

This directory is a placeholder until the OFL files are added in a future release.
Do not vendor a font until its license and source URL are recorded here.

Planned mpv mapping (PlaybackPolicyOptions):

- `sub-font-provider=auto`
- `sub-fonts-dir=<app>/fonts`
